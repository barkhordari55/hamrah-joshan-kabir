# همراه جوشن — نمونه اولیه ویندوز

این پوشه یک MVP نصب‌پذیر (PWA) است که ختم شخصی و گروهی، سهم روزانه، ثبت قرائت و پیشرفت ۱۰۰ فراز را پیاده‌سازی می‌کند.

## اجرای محلی

پوشه را با یک وب‌سرور محلی باز کنید. نمونه با Node.js:

```powershell
npx serve .
```

سپس آدرس نمایش‌داده‌شده را در Microsoft Edge باز و از منوی مرورگر گزینه `Apps > Install this site as an app` را انتخاب کنید.

## محدودیت‌های عمدی MVP

- متن دعا هنوز وارد نشده و باید از منبع تأییدشده تهیه شود.
- اطلاعات فعلاً فقط روی همان دستگاه ذخیره می‌شوند.
- حالت گروهی در رابط و مدل محلی وجود دارد؛ دعوت اعضا و همگام‌سازی به بک‌اند نیاز دارد.
- برای اعلان زمان‌بندی‌شده در حالت بسته بودن برنامه، بسته‌بندی ویندوز و سرویس اعلان لازم است.
